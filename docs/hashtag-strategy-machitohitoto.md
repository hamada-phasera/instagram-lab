## 3. 設計方針

1. **小規模アカウントの原則**: フォロワー1,000未満では巨大タグ（100万件超）の上位表示は困難。**スモール（〜1万件）〜ミドル（1〜10万件）を主軸**にし、巨大タグは各投稿1〜2個まで。
2. **個数**: Instagram 公式は 3〜5個推奨。実務上は **5〜10個** に収める（羅列しすぎはスパム見えのリスク）。
3. **リールの実態**: 現在のリール到達はレコメンド主体でタグの寄与は低下したが、**ローカル・ニッチ発見**（「石巻」で探す人）には依然有効。地名タグを最優先。
4. **公式リグラム狙い**: 公式が巡回するタグ（#いしのまき日和 / #東北PR局）は、小規模アカウントでも公式アカウントに紹介されれば一気にリーチが伸びる可能性がある「くじ」。コスト0なので常用。
5. **ブランドタグの資産化**: #まちと人と #まきボラ 等の独自タグを全投稿に固定 → 参加者の UGC が同タグに蓄積し、後から活動アーカイブとして機能。

## 5. コンテンツ別モジュール（基本セットに +2〜4個）

```

### C. 若者・探究・教育（ミライブラリー / ムムム！ / 高校連携）
```
#探究学習 #キャリア教育 #高校生 #若者応援
```

### D. ボランティア・イベント（まきボラ / DIVE!）★本案件の主戦場

投稿の**目的**でタグの客層を切り替える（2026-08-27 に本案件の動画は D と確定）。

**D-1. 募集投稿（イベント前・参加者を集める）**
```
#まきボラ #ボランティア募集 #学生ボランティア #ボランティア #大学生
```
- 届けたい相手 = 参加を迷っている若者。#ボランティア募集（数万・目的一致度が高い）と #学生ボランティア（数万）が主軸
- #大学生 / #高校生 は巨大タグ（数百万目安）なので **どちらか1つまで**。ターゲット学齢に合わせて選ぶ
- 夏募集なら #夏休み、告知圏を広げたい時は #東北 を追加

**D-2. 活動レポート（イベント後・地域と参加者に見せる）**
```
#まきボラ #ボランティア #地域イベント #地域貢献 #ボランティア活動
```
- 届けたい相手 = 地域の大人・協力団体・参加した本人（保存/シェアされやすい）
- #地域貢献（十数万目安）は企業・行政系の目にも留まりやすい。公式リグラム枠 #いしのまき日和 との相性も良い
- 参加者に「#まきボラ を付けて投稿してね」と声かけし、UGC をブランドタグに蓄積する

サイズ目安: #ボランティア 数十万〜100万 / #ボランティア募集 数万 / #学生ボランティア 数万 / #ボランティア活動 十数万 / #地域イベント 数万〜十数万 / #地域貢献 十数万（いずれも要実測）。

### E. 移住・関係人口（石巻人事部・UIターン文脈）
```

## 6. 運用ルール

0. **リールのレバー優先順位**（本案件の形式）: タグは5番手の補助信号。効く順に
   ① 冒頭1〜2秒のフック（結論・意外性を先に）
   ② 完視聴率（15〜30秒尺に収める。長尺は分割）
   ③ キャプション1行目の検索キーワード（「石巻 ボランティア」等の自然文。Instagram 検索・Google 検索の索引対象）
   ④ 音源選び（トレンド音源 or 原音の使い分け）
   ⑤ ハッシュタグ（3〜5個・TL;DR ③のセット）
   カバー画像には文字入れ（プロフィールグリッドからの回遊対策）。
1. **位置情報タグを必ず付ける**（「石巻市」または撮影スポット名）。ローカルリーチの基本。
2. **@visit_ishinomaki 等の公式をメンション/タグ付け** → リグラム機会を作る。
3. キャプション1行目はフック文（タグは末尾にまとめる。タグで始めない）。
4. コンテスト期間（例年12月〜2月・#いしのまき日和 リール部門）は応募形式に合わせて投稿。
5. **30日サイクルで検証**: インサイト → リーチ → 「ハッシュタグから」の数値を記録し、下位タグを Tier 内で入れ替える。
6. 表現ルール: 効果は常に「推定」「目安」と表記（断定しない）。
